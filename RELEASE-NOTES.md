# Release Notes — Initial Organization Demo

## Purpose

Provide a standalone concept site for outreach to VA-recognized veterans organizations and accredited representatives without exposing the production Claim Compass application or accepting real veteran records.

## Included

- Organization-focused product narrative
- Responsive public-facing layout
- Fictional interactive claim-review preview
- Three mock condition workspaces
- Mock source-page traceability dialog
- Controlled pilot model
- Responsible-use and non-affiliation language
- Brochure URL/call-to-action copy
- Azure Static Web Apps configuration
- GitHub Pages CNAME support
- Static validation script and GitHub Actions checks

## Explicit limitations

- No authentication
- No uploads
- No database or API
- No contact-form transmission
- No analytics or tracking
- No real veteran or claimant information
- Not intended for production claim review

## Proposed brochure URL

`claimcompass-demo.kneco.com`

This hostname is included as the intended deployment target but will not resolve until the repository is deployed and the required DNS record is created.
